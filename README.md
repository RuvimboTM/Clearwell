# Clearwell Foundation

A responsive website for a fictional clean-water charity, built with ASP.NET Core Razor Pages as a portfolio project.

> Clearwell is not a real organization. No real donations are taken.

## About the project

Clearwell builds boreholes and filtration systems at rural schools and clinics. This site shows how a small non-profit could present its work, take volunteer sign-ups, list events and accept donations.

## Pages

- **Home:** hero section, what the charity does, and a funding progress bar
- **About:** mission, approach and team
- **Events:** upcoming fundraising events with RSVP buttons
- **Donate:** donation form (demo only)
- **Volunteer:** sign-up form
- **Contact:** contact form

## Tech stack

- C# and ASP.NET Core Razor Pages
- HTML5 and CSS3 (custom styles, responsive layout, CSS Grid and Flexbox)
- Visual Studio and Git

## Features

- Responsive design that works on phones, tablets and desktops
- Shared layout with navigation and footer across all pages
- Accessible markup: skip link, visible keyboard focus, labelled form fields
- Client-side form validation

## Run it locally

1. Install [Visual Studio](https://visualstudio.microsoft.com/) with the **ASP.NET and web development** workload.
2. Clone the repo:
   ```
   git clone https://github.com/YOUR-USERNAME/Clearwell.git
   ```
3. Open the solution file in Visual Studio.
4. Press **F5** to run.
